# 用户画像：个人 TickTick APK

<!-- 初稿日期: 2026-10-02 -->

## Persona 1：唯一使用者

- **背景**：个人长期管理日常任务，仅在自己的荣耀 200 上使用。
- **目标**：快速记录、按时间尺度浏览、准点收到提醒，并长期保留任务数据。
- **痛点**：不希望被账号、清单分类和复杂项目管理打断；需要清晰的逾期和重复任务行为。
- **现在的土办法**：使用滴答清单或系统提醒，但界面和功能范围不完全符合预期。
- **技术水平 / 使用习惯**：熟悉 Android 应用；偏好深色、高信息密度、少步骤操作。
- **决策角色**：唯一使用者、需求方和验收者。
