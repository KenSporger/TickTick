# 界面规格：个人 TickTick APK v1

> 视觉基线为滴答清单「今天」页与「月视图」的布局（原始截图不入库）。本文只描述逐屏布局与控件行为。

<!-- 初稿日期: 2026-10-02 -->

## A. 今天 / 已过期

**A1 今天—默认**

```text
┌──────────────────────────────┐
│ 17:05                  43%   │
│ ☰  今天              ◇  ⋮   │
│ 已过期        [ 今天 ]       │
│ ┌──────────────────────────┐ │
│ │ □ 阅读书籍        13:00 │ │
│ │                 ↻  ⏰   │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ □ 明天交材料        全天 │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ ☑ 运动            17:00 │ │ ← 置灰沉底
│ └──────────────────────────┘ │
│                       ( ＋ ) │
│   ✓       日历      搜索  ◇ │
└──────────────────────────────┘
```

- 可点：已过期标签、任务完成框、任务卡、加号、底部日历、底部搜索。
- 任务卡：点击打开 B2；完成框即时完成并允许撤销。
- 系统返回：退出应用或回到系统上一层。

**A2 已过期—有任务**

```text
┌──────────────────────────────┐
│ ☰  今天                 ⋮    │
│ [ 已过期 3 ]      今天       │
│ 10月1日                      │
│ ┌──────────────────────────┐ │
│ │ □ 提交材料        10月1日│ │ ← 日期红色
│ └──────────────────────────┘ │
│ 9月29日                      │
│ ┌──────────────────────────┐ │
│ │ □ 阅读书籍   ↻ ⏰ 13:00 │ │ ← 时间红色
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 最近过期日期在上；标题保持高亮。
- 完成后移出；改期后移到相应视图；无任务时显示简洁空态。

## B. 创建 / 编辑半屏

**B1 创建任务**

```text
┌──────────────────────────────┐
│         原页面变暗            │
│                              │
│ ╭──────────────────────────╮ │
│ │            ━             │ │
│ │ 明天下午三点健身          │ │
│ │ [明天 15:00 ×] [准时提醒]│ │
│ │ 日期与时间    明天15:00 ›│ │
│ │ 提醒              准时 ›│ │
│ │ 重复            不重复 ›│ │
│ │ 取消              [保存] │ │
│ ╰──────────────────────────╯ │
└──────────────────────────────┘
```

- 保存：标题非空且日期合法时可用。
- 点遮罩或下滑：若无修改则关闭；有修改则询问是否放弃。
- 系统返回：同点遮罩。

**B2 编辑任务**

- 与 B1 同构，预填任务信息。
- 左下显示红色“删除”；右下显示“保存修改”。
- 重复实例修改后进入 F1；删除进入 F2。

## C. 日期与时间

**C1 单日**

```text
┌──────────────────────────────┐
│ ‹ 日期与时间          完成   │
│ [ 单日 ] [ 时间段 ]          │
│        十月 2026             │
│ 一 二 三 四 五 六 日          │
│ ...                          │
│ 全天                 开/关   │
│ 时间                 15:00 › │
│ 今天  明天  后天  无日期      │
└──────────────────────────────┘
```

- 全天开启：只有日期，不显示时刻，不自动提醒。
- 全天关闭：显示时间选择。
- 无日期：进入「收集箱」，从今天/周/月移除，但可搜索。已排期任务可通过「移到收集箱」取消排期。

**C2 跨天时间段**

```text
┌──────────────────────────────┐
│ ‹ 日期与时间          完成   │
│ [ 单日 ] [ 时间段 ]          │
│ 全天                   开启  │
│ 开始              10月1日 › │
│ 结束              10月2日 › │
└──────────────────────────────┘
```

- 结束日早于开始日时“完成”禁用。
- 本期跨天任务为全天日期范围，不做跨天具体时刻范围。

## D. 提醒

**D1 提醒选择**

```text
┌──────────────────────────────┐
│ ‹ 提醒                完成   │
│ ● 准时提醒                   │
│ ○ 提前 5 分钟                │
│ ○ 提前 10 分钟               │
│ ○ 提前 30 分钟               │
│ ○ 自定义时间                 │
│   关闭提醒                   │
│ ──────────────────────────── │
│ 通知权限              已允许 │
│ 精确闹钟              已允许 │
│ 后台运行              去检查 │
└──────────────────────────────┘
```

- 无时间任务默认关闭提醒，但允许用户选一个具体提醒时刻。
- 权限不足时显示“可能延迟”或“不可用”，仍允许保存任务。

## E. 重复

**E1 重复规则**

```text
┌──────────────────────────────┐
│ ‹ 重复                完成   │
│ ○ 不重复                     │
│ ● 每天                       │
│ ○ 工作日                     │
│ ○ 每周指定星期             › │
│ ○ 每月指定日期             › │
│ ──────────────────────────── │
│ 结束方式        指定次数    › │
│ 重复次数             10 次   │
└──────────────────────────────┘
```

- 每周指定星期：周一至周日多选，至少一个。
- 每月指定日期：默认任务开始日，可改为 1–31。
- 指定次数：正整数，包含首次。

## F. 重复实例作用范围

**F1 编辑范围**

```text
╭──────────────────────────────╮
│ 修改重复任务                  │
│ 这项修改要应用到哪里？        │
│ ● 仅本次                     │
│ ○ 本次及以后                 │
│              取消  [确定]    │
╰──────────────────────────────╯
```

**F2 删除范围**

- 选项：“删除仅本次”“删除本次及以后”。
- 明示“已经完成或跳过的历史记录会保留”。

## G. 周视图

**G1 七天大格子**

```text
┌──────────────────────────────┐
│ 十月 · 本周            ▦  ⋮ │
│ [ 周 ]  月             ‹  › │
├──────────────┬───────────────┤
│ 周一 28      │ 周二 29       │
│ ☑ 阅读 13:00│ □ 长笛 16:00 │
├──────────────┼───────────────┤
│ 周三 30      │ 周四 10月     │
│ 出差 1/2     │ 出差 2/2      │
├──────────────┼───────────────┤
│ 周五 2       │ 周六 3        │
│ □ 运动 17:00│ ↻ 长笛 16:00 │
├──────────────────────────────┤
│ 周日 4                       │
│ □ 总结一周   □ 准备下周资料 │
└──────────────────────────────┘
```

- 内容区无整体纵向滚动；七格固定铺满。
- 左右滑或箭头切周；点格子打开当日完整列表；长按空白创建该日任务。
- 格内溢出显示“还有 N 项”。

## H. 月视图

**H1 截图式月网格**

- 月视图：左上紧凑月历，其余为两列日期任务面板。
- 上下浏览前后月份；点紧凑月历日期定位对应日期卡。
- 三点菜单包含“显示已完成”“回到今天”。
- 过去完成项整体置灰；未来未完成保持高亮；跨天任务在每个覆盖日显示序号。

## I. 搜索

**I1 搜索—默认**

```text
┌──────────────────────────────┐
│ ‹ [ 搜索任务名称…         ] │
│ 最近编辑                     │
│ □ 阅读书籍         今天13:00│
│ ☑ 出差准备       10月1—2日 │
└──────────────────────────────┘
```

**I2 搜索—有结果**

- 输入即时更新；匹配文字高亮。
- 未完成在前；已完成置灰；逾期日期标红。
- 点击结果打开 B2。

**I3 搜索—无结果**

- 显示“没有找到相关任务”，保留输入框和清除按钮。

## J. 同步状态

- 等待同步：任务卡角落显示小型云状/旋转状态，不阻挡操作。
- 同步失败：顶部短条“同步失败，点按重试”，本地修改继续保留。
- 恢复联网并成功：状态安静消失，不弹成功对话框。
