# 界面规格：TickTick 服务器绑定 v1.1

> 本文只描述 Android App 的服务器绑定界面。既有任务、日历、搜索交互继续以 `../v1-personal-ticktick/interaction.md` 为准。

## 构建模式分流

- **知识背包统一 APK**：未保存服务器绑定时进入 A1；绑定成功后后续启动直接进入现有任务首页。
- **独立部署 APK**：构建时已经预置服务器 URL，启动后直接同步并进入现有任务首页，不出现本文 A～D 页面。
- 已绑定用户更换服务器时，点击左上角菜单，从左侧导航栏进入“服务器”。

## A. 首次启动

**A1 连接服务器**

```text
┌──────────────────────────────┐
│ 09:41                 72%    │
│                              │
│            ✓                 │
│                              │
│      连接你的滴答服务器       │
│                              │
│  在电脑上的知识背包中打开     │
│  “滴答清单 → 绑定服务器”      │
│                              │
│      [ 扫描服务器二维码 ]     │
│                              │
└──────────────────────────────┘
```

- 从：统一 APK 首次启动，且本机没有有效服务器绑定。
- 可点：“扫描服务器二维码”进入 B1。
- 系统返回：退出 App；不生成半绑定状态。
- 页面不展示服务器 URL 输入框，避免普通用户手抄地址。

## B. 扫描与备用输入

**B1 首次请求相机权限**

使用 Android 系统权限弹窗，权限用途文案为“用于扫描知识背包生成的服务器绑定二维码”。

- 允许：进入 B2。
- 拒绝：回到 A1并说明必须允许相机权限才能扫码绑定。
- 永久拒绝：显示“前往系统设置”，不循环弹系统权限。

**B2 扫描服务器二维码**

```text
┌──────────────────────────────┐
│ ‹ 绑定服务器                 │
│                              │
│    ┌────────────────────┐    │
│    │                    │    │
│    │    将二维码放入     │    │
│    │      框内           │    │
│    │                    │    │
│    └────────────────────┘    │
│                              │
│  扫描知识背包中的服务器二维码 │
└──────────────────────────────┘
```

- 从：A1 或 E2。
- 识别到二维码后立即停止相机预览并进入 C1，不要求用户确认服务器地址。
- 非服务器绑定二维码：保持扫描页，底部提示“这不是有效的服务器绑定码”。
- 系统返回：首次绑定回 A1；重新绑定回 E2。

## C. 连接与首次同步

**C1 正在绑定**

```text
┌──────────────────────────────┐
│                              │
│            ◌                 │
│                              │
│        正在连接服务器         │
│       请保持网络连接          │
│                              │
└──────────────────────────────┘
```

- 校验绑定码期间不允许再次提交。
- 系统返回：弹出“停止绑定？”；确认后回到扫描页，原有绑定不变。

**C2 正在首次同步**

```text
┌──────────────────────────────┐
│                              │
│            ✓                 │
│                              │
│        服务器连接成功         │
│       正在同步你的任务…       │
│                              │
└──────────────────────────────┘
```

- 连接验证成功后才把新绑定标记为候选；首次同步成功后正式替换原绑定。
- 同步成功后短暂停留并进入现有“今天”页。

## D. 失败状态

**D1 绑定码已过期**

```text
┌──────────────────────────────┐
│          绑定码已失效         │
│                              │
│ 请在知识背包的“绑定服务器”    │
│ 窗口中刷新二维码，然后重新扫描。│
│                              │
│       [ 重新扫描 ]            │
└──────────────────────────────┘
```

- 不保存二维码中的连接信息。
- “重新扫描”回 B2。

**D2 无法连接服务器**

```text
┌──────────────────────────────┐
│         无法连接服务器        │
│                              │
│ 请检查手机网络以及服务器状态。 │
│                              │
│        [ 重新尝试 ]            │
└──────────────────────────────┘
```

- “重新尝试”使用当前候选绑定重新连接。
- 系统返回回到 B2 扫码页。
- 若从重新绑定进入，原服务器继续可用。

**D3 首次同步失败**

- 标题：“服务器已连接，任务同步失败”。
- 提供“重新同步”和“返回原服务器”（仅重新绑定时）。
- 不要求重新扫描仍然有效的绑定码。

## E. 左侧导航与服务器设置

**E1 左侧导航栏**

```text
┌──────────────────────────────┐
│┌──────────────────────┐      │
││ ✓  滴答清单           │ 暗色 │
││                      │ 遮罩 │
││   服务器                │      │
││   关于                │      │
│└──────────────────────┘      │
└──────────────────────────────┘
```

- 从：任务页左上角菜单按钮。
- 导航栏从左侧推出，覆盖约四分之三屏宽；原页面保留在右侧暗色遮罩下。
- 可点：“服务器”进入 E2；“关于”进入已有关于页面。
- 点右侧遮罩、向左滑动或系统返回：关闭导航栏，回到原页面。
- 底部导航始终保持“任务、日历、搜索、收集箱”，不增加“我的”。

**E2 服务器设置**

```text
┌──────────────────────────────┐
│ ‹ 服务器                     │
│                              │
│ 状态                 ● 已连接│
│ 服务器                已绑定 │
│ 上次同步                刚刚 │
│                              │
│       [ 重新绑定服务器 ]      │
└──────────────────────────────┘
```

- 从：E1 左侧导航栏中的“服务器”。
- 不展示完整绑定凭证；服务器地址默认折叠或脱敏。
- “重新绑定服务器”进入 B2。
- 新服务器首次同步成功前，原绑定持续生效。
- 系统返回：回到打开导航栏前的任务页面。

## F. 进入既有任务首页

绑定成功后进入既有“今天”页，不新增完成对话框。首次进入时仅显示短暂提示“服务器已绑定，任务已同步”。以后启动 App 不再出现绑定页面。底部四项保持“任务、日历、搜索、收集箱”；服务器入口位于左上角菜单打开的导航栏中。
