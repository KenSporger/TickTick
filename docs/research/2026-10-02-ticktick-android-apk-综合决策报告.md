# 仿滴答清单 Android APK 综合决策报告

- 日期：2026-10-02
- 调研级别：L3
- 工作流：W4 最佳实践 + W3 技术评估
- 当前状态：调研完成，产品与技术决策待用户确认

## 执行摘要

本项目可以用纯本地 Android APK 实现。两张用户截图应作为“今天”页和“月视图”的视觉真值，当前滴答清单官方资料只用于验证静态截图看不到的行为；这是因为官方界面近年已有版本变化。

推荐候选路线是 Kotlin + Jetpack Compose + Room。任务浏览、创建、完成和提醒均可离线工作；中文日期时间采用受限且可解释的本地规则解析，并始终显示解析结果、允许撤销或手动覆盖。分钟级提醒由 AlarmManager 承担，WorkManager 不用于定点通知；通知权限、精确闹钟权限、重启恢复和厂商省电限制必须进入产品状态与测试范围。

## 关键发现

1. 【截图已验证】“今天”页由顶栏、已过期/今天选择条、单列任务卡、悬浮创建按钮和四项底栏构成。
2. 【截图已验证】“月视图”不是普通月历，而是“紧凑月历 + 两列分日任务面板”的连续网格。
3. 【截图已验证】未完成任务高亮；过去已完成任务整体降亮、置灰。
4. 【官方已验证】Today 属于智能清单；任务可从右下角 `+` 创建，左侧方框可完成。
5. 【官方已验证】标题中的“明早九点”等内容可被识别为日期、时间和提醒，用户也可手动设置。
6. 【官方已验证】月视图可切月、回到今天并显示或隐藏已完成任务；截图版本的精确手势仍有不确定项。
7. 【技术已验证】纯本地 MVP 可行，Room 可作为唯一数据真值；提醒调度只是可重建的派生状态。
8. 【技术已验证】WorkManager 不保证指定分钟执行，不适合承担到点提醒；分钟级提醒应使用 AlarmManager。
9. 【技术已验证】现成 JVM 中文日期解析方案存在覆盖或维护限制；MVP 更适合受限白名单规则，外加人工选择兜底。
10. 【风险】Android 12+ 精确闹钟、Android 13+ 通知权限、Android 14+ 默认限制以及不同 OEM 的省电策略，会影响“准点”承诺。

## 复用分析

| 方案/组件 | 策略 | 理由 |
|---|---|---|
| 用户提供的两张截图 | 🟢 直接作为视觉基线 | 与目标版本的匹配度最高 |
| 滴答清单官方帮助资料 | 🟡 借鉴交互语义 | 当前界面版本可能与截图不同 |
| Jetpack Compose | 🟢 推荐候选 | 适合原生 Android 声明式复杂状态 UI |
| Room | 🟢 推荐候选 | 适合本地任务查询、事务、迁移和未来 repository 边界 |
| AlarmManager | 🟢 直接用并封装策略层 | Android 指定时点提醒的系统机制 |
| WorkManager | 🟡 仅用于可延迟维护 | 不保证指定分钟执行 |
| `xk-time` / Time-NLP | 🟡 语料对照与规则借鉴 | 直接依赖前仍需许可证、维护度、体积和 Android 兼容验证 |
| Recognizers-Text Java | 🔵 仅参考 | 当前 Java DateTime 未注册中文 |
| Duckling 服务 | 🔵 未来候选 | 纯本地 MVP 引入服务端过重 |
| 中文受限规则解析器 | ⚪ 自己写 | 语法可控、离线、可解释、易形成金标测试 |

## 推荐方案

在用户确认范围后，首版采用 Android-only、local-first：Kotlin + Compose + Room；只实现截图对应的“今天”和“月视图”及其直接创建/编辑闭环，不加入账号、同步、协作、番茄、习惯和第三方日历。创建任务时解析有限中文日期时间词并显示识别标签；手动选择始终拥有更高优先级。提醒分为“准时可用”“可能延迟”“不可用”三种可见状态，不静默承诺所有设备绝对准时。

## PRD 框架草案

- **核心用户**：待确认是个人自用、演示交付还是公开发布。
- **核心页面**：今天页、月视图、快速创建/编辑覆盖层。
- **核心行为**：查看逾期与今日任务；浏览前后日期任务；完成/恢复；一句话创建；手动日期时间；到点提醒。
- **视觉目标**：在约定基准设备与深色模式下复刻两张截图，不用 2026 当前版界面覆盖截图。
- **主要风险**：截图历史版本的隐藏交互未知；提醒受权限和 OEM 影响；自然语言存在歧义；“1:1”验收基准尚未定义。
- **明确待澄清**：发布渠道、目标设备/系统、视觉验收标准、任务范围、提醒误差、解析白名单、重复任务、完成态规则、数据导出/同步边界。

## 不确定项

1. 今天页是否支持横滑切换“已过期/今天”。
2. 月页两个顶栏图标的准确功能，以及点击日期是否定位日卡。
3. 截图中叉号代表放弃还是另一种完成状态。
4. “今天”页如何展示当日已完成任务。
5. 目标 Android 版本、OEM、发布渠道和提醒允许误差。
6. 无年份日期、周几、十二点和跨时区的解释规则。
